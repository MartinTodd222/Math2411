Chapter 3 — Random Variables (3.1–3.2)

Translating outcomes into numbers. Discrete random variables, their distributions, means and variances — and the linearity rules that make computations painless.

3.1 Random variables

Definition A random variable $X: S \to \mathbb{R}$ is a function from the sample space to the real line: it assigns a number $X(s)$ to each outcome $s \in S$.
  • Capital letters ($X, Y, Z$) for random variables; lowercase ($x, y, z$) for their realizations.
  • Always remember: an r.v. is a function, not a number.
  • Statements about $X$ translate into events in $S$: $$\{X = x\} = \{s \in S \mid X(s) = x\}, \qquad P(X = x) = P(\{s \in S \mid X(s) = x\})$$

3.2 Probability mass function (pmf)

Definition The pmf of a discrete r.v. $X$ with range $\chi$ is $$p(x) = P(X = x)$$ with the two defining properties:
  1. $0 < p(x) \le 1$ for $x \in \chi$, and $p(x) = 0$ for $x \notin \chi$.
  2. $\displaystyle \sum_{x \in \chi} p(x) = 1$.

The probability that $X$ lies in a set $A \subseteq \mathbb{R}$ is $$P(X \in A) = \sum_{x \in A} p(x),$$ summing only over the possible values in $A$.

Pitfall — < vs. ≤ For discrete r.v.'s, whether an endpoint is included matters whenever it is a possible value. $P(X < 3) \ne P(X \le 3)$ when $3$ is a possible value — they differ by exactly $p(3)$.
Worked example — sum of two dice $X$ = sum of two fair dice. Possible values 2 to 12. $$p(x) = \frac{6 - |x - 7|}{36}, \quad x = 2, \ldots, 12$$ So $p(2) = p(12) = 1/36$, ..., $p(7) = 6/36$. The pmf is symmetric about 7.

Cumulative distribution function (cdf)

Definition $$F(x) = P(X \le x) \quad \text{for all real } x$$ For a discrete r.v., $F(a) = \sum_{x \le a} p(x)$.

Properties of the cdf

  • $F$ is non-decreasing, with $\lim_{x \to -\infty} F(x) = 0$ and $\lim_{x \to \infty} F(x) = 1$.
  • For a discrete r.v., $F$ is a step function: it jumps at each possible value, and the jump size at $a$ equals $p(a)$.
  • Each step is closed on the left, open on the right ($F$ is right-continuous).
  • From cdf back to pmf: if the range is $x_1 < x_2 < \cdots$, then $$p(x_j) = F(x_j) - F(x_{j-1}), \quad p(x_1) = F(x_1).$$

Interval probability using the cdf

For any $a < b$: $$P(a < X \le b) = F(b) - F(a)$$ This formula applies only to $a < X \le b$ (strict less-than on the left, less-or-equal on the right). For other combinations, convert:
ProbabilityIn terms of F
$P(X \le b)$$F(b)$
$P(X < b)$$F(b) - p(b)$
$P(X > a)$$1 - F(a)$
$P(X \ge a)$$1 - F(a) + p(a)$
$P(a < X \le b)$$F(b) - F(a)$
Worked example — pmf → cdf Given $p(1) = 0.3$, $p(2) = 0.2$, $p(3) = 0.5$: $$F(x) = \begin{cases} 0, & x < 1 \\ 0.3, & 1 \le x < 2 \\ 0.5, & 2 \le x < 3 \\ 1, & x \ge 3 \end{cases}$$ Then $P(0.5 < X \le 2) = F(2) - F(0.5) = 0.5 - 0 = 0.5$, and $P(0.5 < X < 2) = p(1) = 0.3$ (only 1 is in the open interval).

Expectation (population mean)

Definition For a discrete r.v. $X$ with pmf $p(x)$ and range $\chi$: $$\mu = E(X) = \sum_{x \in \chi} x \, p(x)$$ This is a weighted average of the possible values, with the probabilities as weights.
  • $E(X)$ is a number, not random.
  • It is the population mean of the model, not the sample mean $\bar{x}$ of data.
  • It need not be a possible value (one die: $E(X) = 3.5$).
  • Physical interpretation: the balance point of the pmf.
Expectation of a function For any real function $g$: $$E[g(X)] = \sum_{x \in \chi} g(x) \, p(x)$$ You do not need to find the distribution of $g(X)$ first — just plug $g(x)$ into the sum.

Variance and standard deviation

Definition $$\mathrm{Var}(X) = \sigma^2 = \sum_{x \in \chi} (x - \mu)^2 \, p(x) = E[(X - \mu)^2]$$ The standard deviation is $\sigma = \sqrt{\sigma^2}$.
Computational formula (use this one!) $$\boxed{\mathrm{Var}(X) = E(X^2) - [E(X)]^2 = E(X^2) - \mu^2}$$ Usually much faster than the definition. Proof: expand $(X - \mu)^2 = X^2 - 2\mu X + \mu^2$ and take expectations.
Pitfall
  • $\mathrm{Var}(X) \ge 0$ always. If you get a negative number, you made an arithmetic error.
  • $E(X^2) \ne [E(X)]^2$ in general — their difference is the variance, so $E(X^2) \ge [E(X)]^2$.
  • $\mathrm{Var}(-X) = \mathrm{Var}(X)$, not $-\mathrm{Var}(X)$.

Linearity rules — the exam gold

Expectation rules (always true)

  • $E(b) = b$ for a constant $b$
  • $E(aX) = a \, E(X)$
  • $E(aX + b) = a \, E(X) + b$
  • $E(X + Y) = E(X) + E(Y)$ — independence not required

Variance rules

  • $\mathrm{Var}(b) = 0$
  • $\mathrm{Var}(aX + b) = a^2 \, \mathrm{Var}(X)$ — shifting by $b$ doesn't change spread
  • $\mathrm{sd}(aX + b) = |a| \cdot \sigma$
  • $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ only if $X$ and $Y$ are independent
  • Even for independent $X, Y$: $\mathrm{Var}(X - Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ (plus!) because $\mathrm{Var}(-Y) = \mathrm{Var}(Y)$
Independence of random variables $X$ and $Y$ are independent if $$P(X \le x, Y \le y) = P(X \le x) \cdot P(Y \le y) \quad \text{for all } x, y.$$

Problem recipe for discrete r.v.

  1. Range: list the possible values $\chi$.
  2. pmf: find $p(x)$ for each value — usually with counting (Ch 2.3), the multiplication rule (Ch 2.4), or independence (Ch 2.5).
  3. Check: $\sum p(x) = 1$. If the pmf has an unknown constant, solve for it here.
  4. Probabilities: sum $p(x)$ over the right values, or use $F(b) - F(a)$ — watch $<$ vs $\le$.
  5. cdf: cumulative sums, written as a piecewise step function ($\le$ on the left, $<$ on the right of each interval).
  6. Moments: $$E(X) = \sum x \, p(x), \quad E(X^2) = \sum x^2 \, p(x), \quad \mathrm{Var}(X) = E(X^2) - [E(X)]^2$$
  7. Transformations: for $aX + b$, use the linearity rules — don't recompute.
  8. Sums: $E$ of a sum is always the sum of $E$'s; for variance, check independence.

Worked examples

A — Finding a missing constant

Example $X$ has pmf $p(x) = c\,x$ for $x = 1, 2, 3, 4$. Find $c$, $E(X)$, $\mathrm{Var}(X)$.
  • $c(1+2+3+4) = 10c = 1 \Rightarrow c = 1/10$
  • $E(X) = (1 + 4 + 9 + 16)/10 = 3$
  • $E(X^2) = (1 + 8 + 27 + 64)/10 = 10$
  • $\mathrm{Var}(X) = 10 - 9 = 1$
Transformations: $E(3X - 2) = 3(3) - 2 = 7$ and $\mathrm{Var}(3X - 2) = 9 \cdot 1 = 9$.

B — Sampling defective items (pmf from counting)

Example Box of 10 items, 3 defective. Choose 3 at random without replacement; $X$ = number of defectives. $$p(x) = \frac{\binom{3}{x}\binom{7}{3-x}}{\binom{10}{3}} = \frac{\binom{3}{x}\binom{7}{3-x}}{120}$$

C — Finding the pmf via the cdf (max of two dice)

Example $M$ = larger of two fair dice. "$M \le m$" means both dice are $\le m$: $$F(m) = \frac{m}{6} \cdot \frac{m}{6} = \frac{m^2}{36}, \quad m = 1, \ldots, 6$$ pmf from the jumps: $$p(m) = F(m) - F(m-1) = \frac{2m - 1}{36}$$ $$E(M) = \frac{161}{36} \approx 4.47$$ Lesson: for "largest" or "at most" problems, find the cdf first.

D — Insurance (expected profit)

Example Premium $500. During the year: 2% chance of a $10{,}000 claim, 3% chance of a $5{,}000 claim, otherwise none. Profit $Y = 500 - C$.
  • $E(C) = 10000(0.02) + 5000(0.03) = \$350$
  • $E(Y) = 500 - 350 = \$150$
  • $E(C^2) = 10000^2(0.02) + 5000^2(0.03) = 2{,}750{,}000$
  • $\mathrm{Var}(C) = 2{,}750{,}000 - 350^2 = 2{,}627{,}500$, sd ≈ $1621
  • $\mathrm{Var}(Y) = (-1)^2 \mathrm{Var}(C) = 2{,}627{,}500$
Expected profit $150, but very volatile per policy.

E — Unknown probabilities from a given mean

Example $X \in \{0, 1, 2, 3\}$ with $p(0) = 0.1$, $p(1) = a$, $p(2) = b$, $p(3) = 0.2$, $E(X) = 1.6$. Two equations: $$a + b = 0.7 \qquad a + 2b = 1$$ Subtracting: $b = 0.3$, $a = 0.4$. Then $E(X^2) = 0.4 + 1.2 + 1.8 = 3.4$, $\mathrm{Var}(X) = 3.4 - 2.56 = 0.84$.

F — Indicator variables (powerful trick)

Example For any event $A$, define $I_A = 1$ if $A$ occurs, 0 otherwise. Then: $$E(I_A) = P(A), \quad E(I_A^2) = P(A), \quad \mathrm{Var}(I_A) = P(A)[1 - P(A)]$$ Counts are sums of indicators. Toss a fair coin 3 times, $X$ = heads $= I_1 + I_2 + I_3$: $$E(X) = 3 \cdot \tfrac{1}{2} = 1.5, \quad \mathrm{Var}(X) = 3 \cdot \tfrac{1}{2} \cdot \tfrac{1}{2} = 0.75$$ (tosses are independent).

G — Standardization

Example For any r.v. with mean $\mu$ and sd $\sigma > 0$, the standardized variable is $$Z = \frac{X - \mu}{\sigma}$$ Then $E(Z) = 0$ and $\mathrm{Var}(Z) = 1$. $Z$ measures "how many sds $X$ is from its mean".

H — Salesperson (shortcut via linearity)

Example Two independent appointments. First: 70% chance of $1000 commission; second: 40% chance of $1500. Expected commission?

Shortcut: let $X_1, X_2$ be the two commissions. $X = X_1 + X_2$ and $$E(X) = E(X_1) + E(X_2) = 700 + 600 = \$1300$$ No need to find the full joint distribution. (Linearity of expectation doesn't need independence anyway.)

Chapter 3 pitfalls — the T/F traps

  1. An r.v. is a function, not a number.
  2. $P(X < 3) = P(X \le 3)$ — false for discrete r.v.'s whenever 3 is a possible value (they differ by $p(3)$).
  3. The cdf is non-decreasing — it never decreases.
  4. $E(X + Y) = E(X) + E(Y)$ — always true, independence not required.
  5. $\mathrm{Var}(X - Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ for independent $X, Y$ — plus, not minus.
  6. $E(X)$ need not be a possible value (one die: 3.5).
  7. $\mathrm{Var}(X) = 0 \Leftrightarrow X$ is a constant (takes one value with probability 1).
  8. $\mu$ (population mean, a parameter) ≠ $\bar{x}$ (sample mean, a statistic).
  9. $E(X^2) \ne [E(X)]^2$ in general — the difference is $\mathrm{Var}(X)$.
  10. $\mathrm{Var}(aX + b) = a^2 \mathrm{Var}(X)$ — the shift $b$ drops out, and $a$ gets squared.
