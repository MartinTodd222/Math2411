Distributions & moment generating functions

The named families you'll meet in Chapter 3.4 and beyond. Each entry has the pmf/pdf, mean, variance, MGF, and when to use it. Note: distributions and MGF are from Ch 3.4–3.5, officially past the midterm scope, but useful groundwork for the final.

Moment generating function (MGF)

Definition The moment generating function of a random variable $X$ is $$M_X(t) = E(e^{tX})$$ for all $t$ in some neighborhood of 0.
  • Discrete: $M_X(t) = \sum_x e^{tx} p(x)$
  • Continuous: $M_X(t) = \int_{-\infty}^{\infty} e^{tx} f(x)\, dx$

Why MGFs are useful

  1. They generate moments. $E(X^n) = M_X^{(n)}(0)$ (the $n$-th derivative of $M_X$ at 0).
    • $E(X) = M'(0)$
    • $E(X^2) = M''(0)$, so $\mathrm{Var}(X) = M''(0) - [M'(0)]^2$
  2. They uniquely determine the distribution. If $M_X = M_Y$ in a neighborhood of 0, then $X$ and $Y$ have the same distribution.
  3. They play nicely with sums. If $X$ and $Y$ are independent, $M_{X+Y}(t) = M_X(t) \cdot M_Y(t)$.
  4. Linear transformations: $M_{aX+b}(t) = e^{bt} M_X(at)$

Bernoulli(p) — Jakob Bernoulli, Swiss

Model: a single trial with two outcomes — success (prob $p$) or failure (prob $1-p$).

Range$\{0, 1\}$
pmf$p(1) = p$,   $p(0) = 1 - p$. Equivalently $p(x) = p^x(1-p)^{1-x}$ for $x \in \{0,1\}$
Mean$E(X) = p$
Variance$\mathrm{Var}(X) = p(1-p)$
MGF$M(t) = (1-p) + p e^t$
Use whenModeling a single yes/no, success/fail, win/lose event.
Why it matters Bernoulli is the building block. A binomial counts the sum of $n$ independent Bernoullis.

Binomial(n, p)

Model: number of successes in $n$ independent Bernoulli(p) trials.

Range$\{0, 1, 2, \ldots, n\}$
pmf$p(k) = \binom{n}{k} p^k (1-p)^{n-k}$
Mean$E(X) = np$
Variance$\mathrm{Var}(X) = np(1-p)$
MGF$M(t) = [(1-p) + p e^t]^n$
Use whenCounting successes in fixed $n$ independent trials, same $p$ each time, with replacement.
Example Toss a biased coin ($p = 0.3$) 10 times. Probability of exactly 3 heads: $$P(X = 3) = \binom{10}{3}(0.3)^3(0.7)^7 \approx 0.2668$$ $E(X) = 10(0.3) = 3$ and $\mathrm{Var}(X) = 10(0.3)(0.7) = 2.1$.

Geometric(p)

Model: number of trials needed to get the first success.

Range$\{1, 2, 3, \ldots\}$
pmf$p(k) = (1-p)^{k-1} p$
Mean$E(X) = 1/p$
Variance$\mathrm{Var}(X) = (1-p)/p^2$
MGF$M(t) = \dfrac{p e^t}{1 - (1-p)e^t}$  (valid for $e^t(1-p) < 1$)
Use whenCounting trials until first success. "How many tosses until the first head?"
Memoryless$P(X > m + n \mid X > m) = P(X > n)$ — the only discrete memoryless distribution.

Negative Binomial(r, p)

Model: number of trials needed to get the $r$-th success.

Range$\{r, r+1, r+2, \ldots\}$
pmf$p(k) = \binom{k-1}{r-1} p^r (1-p)^{k-r}$
Mean$E(X) = r/p$
Variance$\mathrm{Var}(X) = r(1-p)/p^2$
MGF$M(t) = \left[\dfrac{p e^t}{1 - (1-p)e^t}\right]^r$
NoteNegative Binomial(1, p) = Geometric(p). It is the sum of $r$ independent geometrics.

Hypergeometric(N, K, n)

Model: $N$ objects, $K$ of them are of a special type ("successes"). Draw $n$ at random without replacement. $X$ = number of successes drawn.

Range$\max(0, n - (N-K)) \le k \le \min(n, K)$
pmf$p(k) = \dfrac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}$
Mean$E(X) = n \cdot \dfrac{K}{N}$
Variance$\mathrm{Var}(X) = n \cdot \dfrac{K}{N} \cdot \dfrac{N-K}{N} \cdot \dfrac{N-n}{N-1}$
MGFNo simple closed form.
Use whenDrawing a sample without replacement from a finite population — defective items, lottery, poker.

Binomial approximation

When $n/N < 0.05$ (sample is small vs population), hypergeometric ≈ Binomial(n, K/N). The "finite population correction" factor $(N-n)/(N-1)$ then ≈ 1.

Poisson(λ)

Model: count of events in a fixed interval of time or space, when events happen at an average rate $\lambda$ independently of each other.

Range$\{0, 1, 2, \ldots\}$
pmf$p(k) = \dfrac{e^{-\lambda} \lambda^k}{k!}$
Mean$E(X) = \lambda$
Variance$\mathrm{Var}(X) = \lambda$ (mean = variance is the Poisson fingerprint)
MGF$M(t) = e^{\lambda(e^t - 1)}$
Use whenRare events in continuous time/space: phone calls per hour, typos per page, decays per minute, insurance claims per month.

Poisson approximation to the binomial

When $n$ is large and $p$ is small with $np = \lambda$ moderate, Binomial(n, p) ≈ Poisson(np). Rule of thumb: $n \ge 20$ and $p \le 0.05$.
Example A hotline receives on average 3 calls per hour. Probability of exactly 5 calls in the next hour: $$P(X = 5) = \frac{e^{-3} 3^5}{5!} = \frac{e^{-3} \cdot 243}{120} \approx 0.1008$$

Uniform(a, b) — continuous

Model: all values in $[a, b]$ are equally likely.

pdf$f(x) = \dfrac{1}{b-a}$ for $a \le x \le b$, 0 elsewhere
Mean$E(X) = \dfrac{a+b}{2}$
Variance$\mathrm{Var}(X) = \dfrac{(b-a)^2}{12}$
MGF$M(t) = \dfrac{e^{bt} - e^{at}}{t(b-a)}$  ($t \ne 0$)

Exponential(θ)

Model: time until the next event in a Poisson process. $\theta$ is the mean (some texts use rate $\lambda = 1/\theta$).

pdf$f(x) = \dfrac{1}{\theta} e^{-x/\theta}$ for $x \ge 0$
cdf$F(x) = 1 - e^{-x/\theta}$ for $x \ge 0$
Mean$E(X) = \theta$
Variance$\mathrm{Var}(X) = \theta^2$
MGF$M(t) = \dfrac{1}{1 - \theta t}$ for $t < 1/\theta$
Memoryless$P(X > s + t \mid X > s) = P(X > t)$ — the only continuous memoryless distribution.
Use whenModeling waiting times, lifetimes, time between arrivals.

Normal(μ, σ²) — the bell curve

pdf$f(x) = \dfrac{1}{\sigma \sqrt{2\pi}} \exp\!\left(-\dfrac{(x - \mu)^2}{2 \sigma^2}\right)$
Mean$E(X) = \mu$
Variance$\mathrm{Var}(X) = \sigma^2$
MGF$M(t) = \exp\!\left(\mu t + \dfrac{\sigma^2 t^2}{2}\right)$
Standardize$Z = (X - \mu)/\sigma \sim N(0, 1)$

Key properties

  • Symmetric and bell-shaped around $\mu$.
  • About 68% within 1 sd, 95% within 2 sd, 99.7% within 3 sd of $\mu$.
  • Central Limit Theorem: sample means from any distribution with finite variance tend to a normal distribution as $n \to \infty$.
  • Sum of independent normals is normal: if $X_i \sim N(\mu_i, \sigma_i^2)$ are independent, $\sum X_i \sim N(\sum \mu_i, \sum \sigma_i^2)$.

Which distribution should I use?

If the problem is about…Use…
A single yes/no trialBernoulli
Number of successes in $n$ independent trials, same $p$Binomial
Number of trials to the 1st successGeometric
Number of trials to the $r$-th successNegative Binomial
Sampling without replacement from a finite populationHypergeometric
Count of rare events per interval of time/spacePoisson
Waiting time between Poisson eventsExponential
Continuous value with all parts of an interval equally likelyUniform
Measurement data, sample means, test scoresNormal

Finding E and Var via MGF (worked)

Take $M(t) = e^{\lambda(e^t - 1)}$ (Poisson).
  • $M'(t) = \lambda e^t \cdot e^{\lambda(e^t - 1)}$ → $M'(0) = \lambda \cdot 1 = \lambda$. So $E(X) = \lambda$. ✓
  • $M''(t) = \lambda e^t \cdot M(t) + \lambda e^t \cdot \lambda e^t \cdot M(t) = \lambda e^t M(t) [1 + \lambda e^t]$
  • $M''(0) = \lambda(1 + \lambda) = \lambda + \lambda^2 = E(X^2)$
  • $\mathrm{Var}(X) = E(X^2) - [E(X)]^2 = \lambda + \lambda^2 - \lambda^2 = \lambda$ ✓
