Study plan

  1. Read each chapter module in order. Each one links out to the formula sheet when a rule is used.
  2. Attempt the worked examples on paper first, then compare to the solution shown.
  3. Memorize the formula sheet — it is organized the same way as the chapters.
  4. Review the pitfalls at the end of each chapter the day before the exam. These are the true/false and MC traps.

What is in scope for the midterm

Chapter 1 — Descriptive Statistics

  • Types of variables (nominal, ordinal, discrete, continuous)
  • Mean, median, trimmed mean
  • Variance (s² = Σ(xᵢ − x̄)² / (n−1)), sd, range, IQR
  • Quartiles via np + 0.5
  • Histogram shape (skewness, modality)
  • Boxplot and the 1.5 · IQR outlier rule

Chapter 2 — Probability

  • Sample space, events, set operations, De Morgan
  • Kolmogorov axioms, addition rule, inclusion–exclusion
  • Equally likely outcomes
  • Counting: multiplication, permutations, combinations, partitions, circular
  • Birthday problem (via complement)
  • Conditional probability, multiplication rule
  • Law of total probability, Bayes' theorem
  • Independence (not the same as disjoint)

Chapter 3 — Random Variables (3.1–3.2)

  • What a random variable is (a function from S to ℝ)
  • Discrete r.v., pmf, properties
  • cdf: step function, right-continuous, jumps = p(x)
  • Interval probabilities: watch < vs ≤
  • Expectation E(X) = Σ x · p(x) and E[g(X)]
  • Variance Var(X) = E(X²) − μ²
  • Linearity: E(aX + b), Var(aX + b)
  • Sum rules: E(X + Y) always, Var(X + Y) only if independent

Not in scope for the midterm: Chapter 3.3+ (continuous r.v., named distributions, MGF) and inferential statistics.
