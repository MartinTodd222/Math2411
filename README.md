# MATH 2411 Midterm Review

Interactive study site covering **Chapters 1–3** for the MATH 2411 midterm at HKUST (Fall 2026).

## What's inside

| Page | Contents |
| --- | --- |
| `index.html` | Overview, study plan, scope of each chapter |
| `chapter1.html` | Descriptive statistics: mean, median, variance, quartiles (np+0.5), boxplots, outliers |
| `chapter2.html` | Probability: sample spaces, counting, conditional probability, Bayes, independence |
| `chapter3.html` | Random variables: pmf, cdf, expectation, variance, linearity rules |
| `formulas.html` | One-page formula sheet |

## Run locally

Just open `index.html` in a browser. All math is rendered with MathJax (loaded from CDN, needs internet).

## Deployment

Hosted via **GitHub Pages** from this repository.
