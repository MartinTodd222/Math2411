Descriptive statistics (Chapter 1)

MeasureFormula
Sample mean$\bar{x} = \frac{1}{n}\sum x_i$
Median$x_{((n+1)/2)}$ if $n$ odd; $\tfrac{1}{2}(x_{(n/2)} + x_{(n/2+1)})$ if $n$ even
Sample variance$s^2 = \frac{1}{n-1}\sum (x_i - \bar{x})^2$   ($n-1$ df)
Sample sd$s = \sqrt{s^2}$
Range$x_{\max} - x_{\min}$
Quartile $Q_p$ (course rule)$np + 0.5$ integer $m \to$ $m$-th value; otherwise avg of $m$-th and $(m+1)$-th
IQR$Q_3 - Q_1$
Outlier rule$x \le Q_1 - 1.5 \cdot IQR$ or $x \ge Q_3 + 1.5 \cdot IQR$
Linear transformation$\bar{y} = a\bar{x} + b$,   $s_y = |a| s_x$

Probability (Chapter 2)

RuleFormula
Axioms$P(E) \ge 0$; $P(S) = 1$; countable additivity for disjoint events
Complement$P(A^c) = 1 - P(A)$
Addition$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
Three events (inclusion–exclusion)$\sum P(A_i) - \sum_{i
De Morgan$(A \cap B)^c = A^c \cup B^c$;   $(A \cup B)^c = A^c \cap B^c$
Equally likely outcomes$P(E) = |E|/N$
Conditional$P(A \mid B) = P(A \cap B)/P(B)$
Multiplication$P(A \cap B) = P(A \mid B)P(B) = P(B \mid A)P(A)$
Total probability$P(A) = \sum_i P(A \mid B_i) P(B_i)$
Bayes$P(B_j \mid A) = \dfrac{P(A \mid B_j) P(B_j)}{\sum_i P(A \mid B_i) P(B_i)}$
Independence$P(A \cap B) = P(A) P(B)$

Discrete random variables (Chapter 3)

QuantityFormula
pmf$p(x) = P(X = x)$;  $p(x) \ge 0$, $\sum p(x) = 1$
Set probability$P(X \in A) = \sum_{x \in A} p(x)$
cdf$F(x) = P(X \le x) = \sum_{t \le x} p(t)$
Interval$P(a < X \le b) = F(b) - F(a)$
cdf → pmf$p(x_j) = F(x_j) - F(x_{j-1})$
Mean (expectation)$\mu = E(X) = \sum x \, p(x)$
Expectation of a function$E[g(X)] = \sum g(x) \, p(x)$
Variance (computational)$\sigma^2 = E(X^2) - \mu^2$
Linearity of expectation$E(aX + b) = aE(X) + b$;   $E(X + Y) = E(X) + E(Y)$ (always)
Variance rules$\mathrm{Var}(aX + b) = a^2 \mathrm{Var}(X)$;   $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ (independent only)
Indicator variable$E(I_A) = P(A)$,   $\mathrm{Var}(I_A) = P(A)[1-P(A)]$
Standardization$Z = (X - \mu)/\sigma$ has $E(Z) = 0$, $\mathrm{Var}(Z) = 1$

Interval probability conversions (discrete r.v.)

ProbabilityIn terms of F and p
$P(X \le b)$$F(b)$
$P(X < b)$$F(b) - p(b)$
$P(X > a)$$1 - F(a)$
$P(X \ge a)$$1 - F(a) + p(a)$
$P(a < X \le b)$$F(b) - F(a)$
$P(a \le X \le b)$$F(b) - F(a) + p(a)$
$P(a < X < b)$$F(b) - F(a) - p(b)$
$P(a \le X < b)$$F(b) - F(a) - p(b) + p(a)$

On the exam, in order of priority

  1. Write what you know and what you're asked — in symbols.
  2. Identify the chapter and the matching formula (addition? Bayes? linearity?).
  3. Plug in, simplify, box the answer.
  4. Sanity check: probabilities in $[0, 1]$, variances $\ge 0$, pmfs sum to 1.
  5. Rounding: exact or 4 decimal places.
