Discrete random variables (Chapter 3)

QuantityFormula
pmf$p(x) = P(X = x)$;  $p(x) \ge 0$, $\sum p(x) = 1$
Set probability$P(X \in A) = \sum_{x \in A} p(x)$
cdf$F(x) = P(X \le x) = \sum_{t \le x} p(t)$
Interval$P(a < X \le b) = F(b) - F(a)$
cdf → pmf$p(x_j) = F(x_j) - F(x_{j-1})$
Mean (expectation)$\mu = E(X) = \sum x \, p(x)$
Expectation of a function$E[g(X)] = \sum g(x) \, p(x)$
Variance (computational)$\sigma^2 = E(X^2) - \mu^2$
Linearity of expectation$E(aX + b) = aE(X) + b$;   $E(X + Y) = E(X) + E(Y)$ (always)
Variance rules$\mathrm{Var}(aX + b) = a^2 \mathrm{Var}(X)$;   $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ (independent only)
Indicator variable$E(I_A) = P(A)$,   $\mathrm{Var}(I_A) = P(A)[1-P(A)]$
Standardization$Z = (X - \mu)/\sigma$ has $E(Z) = 0$, $\mathrm{Var}(Z) = 1$

Standard normal: if $X \sim N(\mu, \sigma^2)$, then $Z = (X - \mu)/\sigma \sim N(0, 1)$. Then $P(a \le X \le b) = \Phi((b-\mu)/\sigma) - \Phi((a-\mu)/\sigma)$.

Chebyshev's inequality

For any r.v. with mean $\mu$ and finite variance $\sigma^2$, and any $k > 0$: $$P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}, \qquad P(|X - \mu| < k\sigma) \ge 1 - \frac{1}{k^2}$$

Works for any distribution with finite variance. The bound is loose but universal.

Moment generating function (3.5)

PropertyFormula
Definition$M_X(t) = E(e^{tX})$
$n$-th moment$E(X^n) = M_X^{(n)}(0)$
Mean$E(X) = M'(0)$
Variance$\mathrm{Var}(X) = M''(0) - [M'(0)]^2$
Sum (independent)$M_{X+Y}(t) = M_X(t) M_Y(t)$
Linear transformation$M_{aX+b}(t) = e^{bt} M_X(at)$
UniquenessIf $M_X = M_Y$ near 0, then $X$ and $Y$ have the same distribution

Check: $M_X(0) = 1$ always.
