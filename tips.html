Tips & tricks — pattern recognition cheat sheet

For each problem type, how to recognize it and the shortcut to use. If you only remember the pattern, the formula follows.

Bayes' theorem — how to spot it

Signal words that scream Bayes

  • "Given that the result is positive / defective / observed, what is the probability it came from…"
  • "Posterior probability of…"
  • Any question that reverses the direction of a conditional probability.
  • You know $P(\text{evidence} \mid \text{cause})$ but want $P(\text{cause} \mid \text{evidence})$.

The 3-step method

  1. Identify the partition. What are the mutually exclusive, exhaustive "causes" $B_1, \ldots, B_n$? (The three machines, the two bags, infected vs healthy, car behind each door...)
  2. Label the branches: prior $P(B_i)$ on the first branch, likelihood $P(A \mid B_i)$ on the second.
  3. Compute: $$P(B_j \mid A) = \frac{P(A \mid B_j) P(B_j)}{\sum_i P(A \mid B_i) P(B_i)}$$ Numerator = the one path through $B_j$. Denominator = sum of all paths to $A$.
Shortcut recognition
  • Medical/diagnostic test: prior = prevalence, likelihood = sensitivity/specificity. The low prevalence is why the "base-rate fallacy" strikes.
  • Three machines (defectives): prior = production share, likelihood = defect rate. Posterior tells you which machine was the likely source.
  • Monty Hall: prior = $1/3$ for each door, likelihood depends on which door the host opens.
Don't confuse $P(A \mid B)$ with $P(B \mid A)$ These are generally very different. In the HIV example $P(\text{test}+\mid \text{sick}) = 0.95$ but $P(\text{sick}\mid \text{test}+) \approx 0.004$. Always ask: "what's being conditioned on?"

The "at least one" trick

Signal: words "at least", "at least one", "not all", "some"

Compute the complement. It is almost always easier. $$P(\text{at least one}) = 1 - P(\text{none})$$ $$P(\text{at least two}) = 1 - P(0 \text{ or } 1)$$
Classic examples
  • Birthday problem: $P(\text{some share}) = 1 - \frac{365!/(365-n)!}{365^n}$
  • Rolls of a die until first 6: $P(\text{at least one 6 in }n\text{ rolls}) = 1 - (5/6)^n$
  • n independent trials, success prob p: $P(\text{at least one success}) = 1 - (1-p)^n$

Permutation vs combination — decision tree

Ask yourself in order:

  1. Does order matter?
    • Yes → permutation ($n!/(n-r)!$)
    • No → combination ($\binom{n}{r}$)
  2. Are you dividing into groups? Partition / multinomial: $\dfrac{n!}{n_1!\,n_2!\cdots n_k!}$
  3. Objects in a circle? Divide by rotations: $(n-1)!$
  4. Letters with repeats? Same as partition: divide by factorials of repeat counts.

Hypergeometric vs binomial — one question

With or without replacement?

  • With replacement (or independent trials) → binomial. Each trial has the same probability $p$.
  • Without replacement (sampling from finite population) → hypergeometric. The population composition changes.
BinomialHypergeometric
pmf$\binom{n}{k} p^k (1-p)^{n-k}$$\dfrac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}$
Mean$np$$n \cdot \tfrac{K}{N}$
WhenFlipping a coin, rolling dice, with replacementDrawing from a box, lottery, poker hands

Rule of thumb: if $n$ is small compared to $N$ (say $n/N < 0.05$), the hypergeometric is well-approximated by binomial with $p = K/N$.

Independent vs disjoint — nearly opposites

Common trap "A and B are mutually exclusive, so they're independent." False. If $P(A), P(B) > 0$ and A, B are disjoint, then knowing A happened tells you B did not happen — that's maximum dependence.

Expectation and variance shortcuts

Expectation (always true, no independence needed)

  • $E(aX + b) = aE(X) + b$
  • $E(X + Y) = E(X) + E(Y)$ (linearity)
  • $E[g(X)] = \sum g(x) p(x)$ — don't find the distribution of $g(X)$, just plug in
  • Indicator: $E(I_A) = P(A)$. Counts = sums of indicators!

Variance

  • Use the computational formula: $\mathrm{Var}(X) = E(X^2) - [E(X)]^2$ (always faster than the definition)
  • $\mathrm{Var}(aX + b) = a^2 \mathrm{Var}(X)$ — shift drops, scale squares
  • $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ only if independent
  • $\mathrm{Var}(X - Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ (plus, not minus!)
  • Indicator: $\mathrm{Var}(I_A) = P(A)(1 - P(A))$
  • Sanity check: variance is always $\ge 0$
The indicator sum shortcut "Toss a coin $n$ times. Find $E$ and $\mathrm{Var}$ of the number of heads."
Let $X = I_1 + I_2 + \cdots + I_n$. Then without any pmf: $$E(X) = n \cdot \tfrac{1}{2}, \quad \mathrm{Var}(X) = n \cdot \tfrac{1}{2} \cdot \tfrac{1}{2}$$ This generalizes: any binomial has $E = np$ and $\mathrm{Var} = np(1-p)$.

< vs ≤ for discrete random variables

Critical trap For a discrete r.v., strict vs non-strict inequality matters whenever the endpoint is a possible value.
  • $P(X < 3) = P(X \le 3) - p(3)$
  • $P(X \ge 3) = P(X > 3) + p(3) = 1 - F(3) + p(3)$

Mnemonic: $F(b) - F(a)$ is the "default", which equals $P(a < X \le b)$. For every other combination, add or subtract $p$ at the endpoint that moved.

Quartiles — the np + 0.5 rule

Mechanical procedure

For $p \in \{0.25, 0.50, 0.75\}$, compute $m^* = np + 0.5$.
  • If $m^*$ is an integer $m$ → quartile = $m$-th smallest value.
  • If not → quartile = average of $\lfloor m^* \rfloor$-th and $(\lfloor m^* \rfloor + 1)$-th values.
Pitfall R's quantile() gives different answers. On the exam use $np + 0.5$ or lose points.

Boxplot outlier rule

The 1.5·IQR rule

A point $x$ is an outlier if $x \le Q_1 - 1.5 \cdot IQR$ or $x \ge Q_3 + 1.5 \cdot IQR$.
Note: $\le$ and $\ge$, not strict. A point exactly on the fence is an outlier.

In a boxplot, outliers are drawn as separate dots and the whisker stops at the most extreme non-outlier.

Exam strategy

  1. Scan the paper first. Start with the questions worth most points that you know well. Build confidence.
  2. For every T/F: ask "is there any edge case where this breaks?" Even one counterexample makes it false. Classic traps:
    • "$P(E) \le 1$ is an axiom" — false, it's a consequence
    • "disjoint ⇒ independent" — false
    • "$E(X+Y) = E(X) + E(Y)$ needs independence" — false, linearity is always true
    • "$\mathrm{Var}(X - Y) = \mathrm{Var}(X) - \mathrm{Var}(Y)$" — false, it's a plus
  3. For MC: compute, then check which option matches. If none, you made an arithmetic error.
  4. For long problems: write what you know. Draw a tree if conditional / Bayes. State the formula before plugging in — makes partial credit easier if you make an arithmetic slip.
  5. Sanity checks:
    • Probabilities in $[0, 1]$
    • Variances $\ge 0$
    • pmf sums to 1
    • $E(X^2) \ge [E(X)]^2$
  6. Rounding: exact or 4 decimal places.
  7. Last 10 minutes: re-check every "at least" / complement computation, and re-check every "did order matter" counting question.
